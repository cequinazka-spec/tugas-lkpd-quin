D. Apersepsi

Menurutmu, bagaimana cara menyimpan informasi tersebut di dalam program? Tuliskan dugaanmu!
Jawaban Saya: Informasi tersebut dapat disimpan menggunakan variabel (variable). Variabel berfungsi sebagai penampung data di memori dengan memberikan nama identitas tertentu, contohnya: 
let namaSiswa = "Budi";
let kelas = "X RPL 1";
let umur = 15;
let nilai = 85;
let jurusan = "PPLG";

F. Aktivitas 2 - Mengenal Variable

1. Apa itu Variable dan Bagaimana Anatomi Penulisannya?
Pengertian & Struktur Kode: Variable dapat dianggap sebagai tempat untuk menyimpan sebuah data agar data tersebut dapat digunakan kembali oleh program.

Contoh Kode: let nama = "Andi";

Penjelasan Bagian Kode:
Bagian Fungsi
let Kata kunci untuk membuat / mendeklarasikan variable
nama Nama identitas variable
= Operator assignment untuk memberikan / memasukkan nilai
"Andi" Nilai atau data yang disimpan di dalam variable

H. Aktivitas 4 - Eksperimen

1. Apakah hasil pada Console berubah?
Jawaban Saya: Ya, hasil tampilan di console berubah sesuai dengan data baru yang dimasukkan.
2. Bagian kode mana yang kamu ubah?
Jawaban Saya: Bagian nilai variabel di sebelah kanan tanda sama dengan (=), contohnya mengubah isi teks/string pada let nama, let kelas, dan angka pada let umur.
3. Mengapa program dapat menampilkan data yang baru?
Jawaban Saya: Karena saat nilai variabel diperbarui, memori akan menimpa isi variabel tersebut sehingga perintah console.log() mencetak data paling baru.

J. Aktivitas 6 - Mengenal let dan const

1. Apa yang terjadi pada contoh kode const?
Jawaban Saya: Terjadi kesalahan/error (TypeError: Assignment to constant variable.) karena nilai variabel yang dibuat dengan const tidak bisa diubah nilainya.
2. Kesimpulan Sementara let vs const
Tabel Perbandingan:
Keyword Nilai dapat diubah? Kegunaan sederhana
let Ya Untuk menyimpan data yang nilainya fleksibel / masih mungkin berubah.
const Tidak Untuk menyimpan data tetap / konstan yang tidak perlu diubah.

T. Kesimpulan

Rangkuman Materi:

• Variable adalah: Wadah atau tempat di dalam memori komputer yang digunakan untuk menyimpan data/informasi.

• let digunakan untuk: Mendeklarasikan variabel yang nilainya dapat diubah/diperbarui.

• const digunakan untuk: Mendeklarasikan variabel yang nilainya bersifat tetap (konstan) dan tidak bisa diubah.
